# Features

The Modeler includes several features designed to improve your workflow editing
experience. This section covers features that go beyond basic model editing.

## Feature overview

| Feature | Description |
|---------|-------------|
| [Keyboard Shortcuts](keyboard-shortcuts.md) | Navigate and edit workflows using keyboard-only interactions. |
| **Undo/Redo** | Step back and forward through editing history (up to 50 actions) with keyboard shortcuts or canvas toolbar buttons. |
| [Search & Find](search.md) | Locate nodes and edges by label, plugin, type, or ID. |
| [Dark Mode](dark-mode.md) | Switch between light and dark themes. |
| [Flow Filtering](flow-filtering.md) | Show only specific flows when a model has multiple events. |
| [Export](export.md) | Export models as Recipe, Archive, JSON, or SVG. |
| [Standalone Viewer](standalone-viewer.md) | Embed a read-only workflow viewer in any web page. |
| [View Modes](view-modes.md) | Switch between fullscreen and floating-window display. |
| [Permissions](permissions.md) | Granular permission controls for modeler actions. |
