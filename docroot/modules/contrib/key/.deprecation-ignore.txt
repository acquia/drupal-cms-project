# This file contains patterns to be ignored while testing for use of
# deprecated code. GitLab CI appends core's .deprecation-ignore.txt to it.
# See https://www.drupal.org/node/3285162 for more details.

# Return type deprecations in key's own classes. Adding native return types to
# these extendable classes would break downstream subclasses, so they wait for
# a new major version of key.
%Method "[^"]+::[^"]+\(\)" might add "[^"]+" as a native return type declaration in the future\. Do the same in (?:implementation|child class) "Drupal\\key(?:_test)?\\[^"]+" now to avoid errors or add an explicit @return annotation to suppress this message%
