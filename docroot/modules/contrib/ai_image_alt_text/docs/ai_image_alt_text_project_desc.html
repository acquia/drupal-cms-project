This module is part of the AI module ecosystem and included in DXPR CMS.

Generate accurate, descriptive alt text automatically using AI vision models. Improve accessibility and search rankings while maintaining editorial control through human-in-the-loop verification.

You need AI Image Alt Text if

  • You manage sites with hundreds or thousands of images lacking alt text
  • You need to improve accessibility compliance and SEO rankings
  • Your content team struggles to write consistent, descriptive alt text
  • You want to speed up content publishing while maintaining quality

Features

  • One-click generation: a "Generate" button appears on every image field widget; click it to produce alt text from the uploaded image
  • Human-in-the-loop: review and edit the AI suggestion before saving; editorial control stays with your team
  • Autogenerate on upload: optionally generate alt text the moment an image is uploaded, with no manual step required
  • Multilingual: detects the entity’s language and generates alt text in the corresponding language automatically
  • Customisable prompt: edit the Twig-based prompt template at /admin/config/ai/ai_image_alt_text to match your editorial style
  • Image preprocessing: choose an image style to resize images before sending them to the AI, reducing API costs without sacrificing quality
  • Model flexibility: works with any vision-capable model through the AI module: OpenAI GPT-4o, Anthropic Claude, Google Gemini, Fireworks AI, and others
  • Bulk processing: the included AI Image Bulk Alt Text sub-module lets you generate or regenerate alt text for existing images across your entire site

SEO benefits

Generating accurate and descriptive alt texts enhances your website's accessibility and improves search engine optimization (SEO). Alt texts help search engines understand image content, which can improve your site's ranking in image search results. By using this module, you ensure high-quality, consistent alt text generation that adheres to best practices for both accessibility and SEO.

Installation

composer require drupal/ai_image_alt_text
drush en ai_image_alt_text

To enable bulk processing of existing images, also enable the sub-module:

drush en ai_image_bulk_alt_text

Post-installation

  1. Set up permissions to determine which roles can generate alt texts using AI.
  2. Access the settings page at /admin/config/ai/ai_image_alt_text to customize the prompt or adjust how the image is preprocessed before being sent to the AI.
  3. A button will then appear on image fields for generating alt texts.

This module uses the AI module as its foundation. It supports any vision model available through providers like OpenAI, Anthropic, and Fireworks AI.

FAQ

Which AI models does AI Image Alt Text support?

The module works with any vision model available through the Drupal AI module, including OpenAI (GPT-4o), Anthropic (Claude), Google (Gemini), and Fireworks AI. Switch models at any time without changing your workflow.

Does the module generate alt text automatically on upload?

By default the module uses a human-in-the-loop approach: a "Generate" button appears next to the alt text field on image widgets. Click it to produce a suggestion, review and edit as needed, then save. You can also enable fully automatic generation on upload in the settings at /admin/config/ai/ai_image_alt_text, with an option to hide the manual button entirely.

Does AI Image Alt Text support multilingual content?

Yes. The module detects the entity’s language setting and generates alt text in the corresponding language. This works automatically with Drupal's multilingual system; no extra configuration is required.

Can I customise the prompt used to generate alt text?

Yes. Visit /admin/config/ai/ai_image_alt_text to edit the prompt template and configure how images are preprocessed before being sent to the AI. You can tailor the instructions to match your editorial style and accessibility requirements.

How does this module improve SEO?

Search engines use alt text to understand image content and index it for image search results. AI Image Alt Text generates accurate, descriptive alt text that follows accessibility best practices, which improves both your search visibility and your WCAG compliance.
