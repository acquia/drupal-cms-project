# AI Dashboard

[AI Dashboard](https://drupal.org/project/ai_dashboard) provides a centralized, user-friendly interface for configuring and managing all AI-powered functionality in your Drupal site. This module replaces the existing AI configuration overview with a comprehensive dashboard that streamlines AI provider setup, feature installation, and system configuration.

## Features

- **Unified AI Provider Management**: Configure multiple AI providers (OpenAI, Anthropic, Groq, and more) from a single interface with easy API key management and provider selection.
- **Organized Feature Installation**: Browse and install AI-powered capabilities organized by content type including Media, Content, Workflow, Assistants, Forms, and Multilingual support. Each category displays available AI features such as LLM Optimized Content, SEO Optimizer, Content Classification, and Image Classification.
-  **Centralized Configuration**: Access all AI-related settings through organized sections including AI Default Settings, AI API Explorer for testing, AI Agents management, and AI Assistants configuration.
- **Extensions Discovery**: Browse contributed projects tagged with the Artificial Intelligence category on Drupal.org directly from the dashboard, so you can find and install new AI-related modules instead of only seeing what is already on your site.
-  **System Status Overview**: Monitor configured providers and default models at a glance with collapsible status panels showing your current AI setup.
- **Integrated Documentation**: Access detailed guides, reference materials, and tutorials for all AI features directly from the dashboard interface.

## Requirements

This module requires the [AI module](https://drupal.org/project/ai) and is designed to enhance its administrative interface. Individual AI features may have additional provider-specific requirements.
